How this version works

  • Longer tokens are matched first, so tS becomes one affricate.
  • ! marks primary stress; ¡ marks secondary stress.
  • r# represents the alveolar tap /ɾ/.
  • : adds the IPA length mark. ~ adds a combining nasalization mark to the preceding character.
  • Ordinary letters and punctuation pass through unchanged unless listed in the symbol key.

WARPT is your custom notation, so this converter follows the mappings currently documented here. Check the symbol key as the system evolves.
